| Version | Supported          |

## Reporting a Vulnerability

We take the security of Online Boutique seriously.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them privately via:

- Email: security@your-org.example.com (replace with your security contact)
- Or open a private security advisory on GitHub: https://github.com/grlokesh96/Online-Boutique/security/advisories/new

We will acknowledge receipt within 48 hours and provide a detailed response within 7 days.

## Scope

This policy covers the core application code in `src/`, Dockerfiles, and Kubernetes manifests.

Third-party dependencies are covered by their respective upstream security policies.
