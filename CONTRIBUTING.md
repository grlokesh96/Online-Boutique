# Contributing to Online Boutique

Thank you for your interest in contributing!

## How to Contribute

1. Fork the repository
2. Create a feature branch from `main`
3. Make your changes
4. Ensure all services still build (`docker compose build`)
5. Open a pull request

## Code Style

- Follow the existing style in each language
- Run `go fmt`, `black`, or `prettier` as appropriate
- Keep commits focused and use Conventional Commits

## Pull Request Process

- One logical change per PR
- Include a clear description of the change and why it is needed
- Link any related issues

## Questions?

Open a GitHub Discussion or reach out via the project maintainers.
